# Сайт массажного салона «Лотос» (Flask + SQLite)

## Запуск

1. Установите Python 3.9+ (https://python.org). При установке на Windows поставьте галочку **Add Python to PATH**.
2. Распакуйте архив, откройте терминал в папке `massage_site`.
3. Установите Flask:
   ```
   pip install flask
   ```
4. Запустите:
   ```
   python app.py
   ```
   (на Mac/Linux: `python3 app.py`)
5. Откройте в браузере: http://127.0.0.1:5000

База данных `salon.db` создастся сама при первом запуске.
Остановить сервер: `Ctrl + C` в терминале.

## Чек-лист тестирования

**Клиент**
1. Откройте сайт → вас перебросит на регистрацию (так и задумано).
2. Попробуйте ошибки: короткий пароль, телефон «123» — должны появиться сообщения.
3. Зарегистрируйтесь → откроется главная: услуги, мастера, адрес.
4. «Записаться» → выберите услугу, мастера, дату → появятся часы. Выберите время → «Записаться».
5. «Мои записи» → запись видна. Нажмите «Отменить».
6. Запишитесь снова, выйдите, зарегистрируйте второго клиента (другой email),
   запишите его **к тому же мастеру на то же время** → время будет зачёркнуто (занято).

**Администратор**
1. Выйдите, войдите: `admin@lotos.local` / `admin123`.
2. Увидите панель: счётчики, записи по датам, имя и телефон клиента.
3. Проверьте фильтр по дате и кнопку «Удалить».
4. Войдите обычным клиентом и откройте http://127.0.0.1:5000/admin — должно не пустить.

**Посмотреть содержимое БД**: установите «DB Browser for SQLite» (бесплатно) и откройте `salon.db`.
Или в терминале: `python -c "import sqlite3; print(sqlite3.connect('salon.db').execute('select * from bookings').fetchall())"`

**Сброс**: остановите сервер, удалите `salon.db`, запустите снова.

## Структура проекта

```
app.py              — вся логика: БД, регистрация, вход, запись, админка
templates/          — HTML-страницы (Jinja2: {{ переменные }}, {% циклы %})
  base.html         — общая шапка для всех страниц
  home.html, register.html, login.html, book.html, my.html, admin.html
static/style.css    — оформление (цвета меняются в :root вверху файла)
salon.db            — база SQLite (создаётся автоматически)
```

## Таблицы БД

- `users` — клиенты и админ (пароли хранятся в виде хэша)
- `services` — виды массажа (название, длительность, цена)
- `specialists` — мастера
- `bookings` — записи: кто, на что, к кому, когда. `UNIQUE(specialist_id, day, time)` не даёт записать двоих на одно время.

## Что изучить дальше (идеи для доработки)

- Смена адреса/телефона салона: словарь `SALON` в app.py
- Добавить новую услугу: строка в `init_db()` (или удалите salon.db после правки)
- Добавить свои фото: положите в `static/`, вставьте `<img src="{{ url_for('static', filename='photo.jpg') }}">`
- Задания: страница «Отзывы», статус записи «подтверждена», отмена записи админом с сообщением клиенту
